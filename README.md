# 🎮 First Game by Snaho (2D Coin Collector)

A fast-paced 2D arcade game built in C using the **Raylib** library. Dodge moving enemies, collect coins to boost your score, and try to score as high as possible within 60 seconds!

---

## ✨ Features
* 🟩 **Player Movement:** Smooth 2D character controls using keyboard arrow keys.
* 🪙 **Dynamic Scoring:** Collect golden coins to score points.
* 🔴 **Increasing Difficulty:** Bouncing red enemies move around the screen. Every coin collected increases enemy speed!
* ⏱️ **Timer System:** 60-second survival countdown.
* 🔄 **Quick Restart:** Press `R` after Game Over to immediately play again.

---

## 🎮 Controls
| Key | Action |
| :--- | :--- |
| **Up / Down / Left / Right** | Move Player |
| **R** | Restart Game (when Game Over) |
