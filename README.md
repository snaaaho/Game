# 🎮 C / Raylib Game Collection

Welcome to the main repository! This project contains multiple 2D arcade games built from scratch in **C** using the **Raylib** game engine framework. 

Each game is maintained separately in its own dedicated branch.

---

## 🕹️ Available Game Branches

| Game | Branch Link | Description | Mode |
| :--- | :--- | :--- | :--- |
| 🪙 **2D Coin Collector** | [`2d-coin-collector`](https://github.com/snaaaho/Game/tree/2d-coin-collector) | Dodge moving hazards, collect coins, and survive before time runs out. | Single-player |
| 🏓 **Pong** | [`Pong`](https://github.com/snaaaho/Game/tree/Pong) | Dynamic local 2-player classic Pong arcade game. | 2-Player (Local) |

---

## 🌿 How to Clone a Specific Game Branch

To clone and run a specific game directly, use the branch flag (`-b`):

```bash
# Clone 2D Coin Collector
git clone -b 2d-coin-collector [https://github.com/snaaaho/Game.git](https://github.com/snaaaho/Game.git)

# Clone Pong
git clone -b Pong [https://github.com/snaaaho/Game.git](https://github.com/snaaaho/Game.git)
```
